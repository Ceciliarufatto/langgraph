# One-pager A4

Material pra distribuir aos visitantes na sessão de painéis. Frente e verso.

## Overleaf

1. Cria projeto em branco.
2. Sobe `one_pager.tex` na raiz.
3. Cria pasta `metrics/` e sobe os três PNGs (`graph.png`, `confusion_matrix.png`, `qrcode_repo.png`).
4. No menu, define `one_pager.tex` como main document.
5. Recompile. Baixa o PDF.

Imprimir frente/verso, 15 a 20 cópias.

## Local

```powershell
cd materiais
pdflatex one_pager.tex
```
